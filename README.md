
# Food Ordering System

## About the Project
A Java Spring Boot backend application developed to manage food items, categories, and customer orders through RESTful APIs.

## Technologies Used
- Java
- Spring Boot
- Spring Data JPA
- MySQL
- REST APIs
- Postman

## Features
- Add, view, update, and delete food items.
- Manage food categories.
- Manage customer orders.
- Perform CRUD operations.
- Store and retrieve data using MySQL.

## Backend Concepts
- RESTful API development
- Spring Data JPA
- Database integration
- CRUD operations

## API Testing
APIs are tested using Postman.
